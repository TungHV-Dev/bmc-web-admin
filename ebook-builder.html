Nhập nội dung từ file Word

File cần dùng bộ Style chuẩn của BMC và công thức được gõ bằng LaTeX.

Kéo thả file .docx vào đây hoặc bấm để chọn file
  • Dùng Style đặt tên: BMC-Theory, BMC-Example, BMC-Question, BMC-Answer
  • Công thức toán đặt trong $...$ (inline) hoặc $$...$$ (block)
  • Hệ thống chỉ tạo bản nháp — cần rà soát lại trong trình soạn trước khi xuất bản
